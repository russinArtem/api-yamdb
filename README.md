### Yamdb API

## Описание:

Проект YaMDb — это платформа для сбора отзывов пользователей на различные произведения (фильмы, книги, музыку и т. д.). В YaMDb не хранятся сами произведения, но можно ознакомиться с их описаниями, отзывами и оценками.

Цель проекта — предоставить REST API для работы с данными платформы YaMDb, позволяя пользователям взаимодействовать с контентом и оставлять свои отзывы.

## Установка:

1. Клонировать репозиторий и перейти в него в командной строке:

```
git clone git@github.com:SgtPepeF/api-yamdb.git
```

```
cd api-yamdb
```

2. Cоздать и активировать виртуальное окружение:

```
python -m venv venv
```

```
source venv/Scripts/activate
```

3. Установить зависимости из файла requirements.txt:

```
python -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

4. Выполнить миграции:

```
python manage.py migrate
```

5. Запустить проект:

```
python manage.py runserver
```

### Примеры запросов:

Пример GET-запроса на получение списка всех категорий.

*GET .../api/v1/categories/*

Пример ответа:

```
[
  {
    "id": 1,
    "name": "Фильмы",
    "slug": "movies"
  },
  {
    "id": 2,
    "name": "Книги",
    "slug": "books"
  },
  {
    "id": 3,
    "name": "Музыка",
    "slug": "music"
  }
]
```

Пример POST-запроса на создание нового жанра.

*POST .../api/v1/genres/*

```
{
  "name": "Джаз",
  "slug": "jazz"
}
```

Пример ответа:

```
{
  "id": 4,
  "name": "Джаз",
  "slug": "jazz"
}
```

Пример GET-запроса на получение информации о конкретном произведении.

*GET .../api/v1/titles/1/*

Пример ответа:

```
{
  "id": 1,
  "name": "Винни-Пух и все-все-все",
  "year": 1969,
  "description": "Мультфильм о приключениях медвежонка Винни-Пуха и его друзей.",
  "category": {
    "name": "Книги",
    "slug": "books"
  },
  "genre": [
    {
      "name": "Сказка",
      "slug": "fairytale"
    }
  ],
  "rating": 9
}
```

Пример POST-запроса на создание отзыва на произведение.

*POST .../api/v1/titles/2/reviews/*

```
{
  "text": "Отличный фильм!",
  "score": 8
}
```

Пример ответа:

```
{
  "id": 1,
  "author": "username",
  "title": "2",
  "pub_date": "2024-04-15T10:00:00Z",
  "text": "Отличный фильм!",
  "score": 8
}
```
